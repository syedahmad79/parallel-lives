# Asset and dependency notes

PARALLEL's narrative text, SVG line illustrations, favicon, star field, social preview composition, and browser-drawn share-card composition were created for this project. No stock photography, external font requests, recorded audio, analytics, or hosted model services are used.

Runtime dependencies: React and React DOM (MIT), Motion (MIT), Lucide React icons (ISC). Build dependencies include Vite, TypeScript, and Tailwind CSS; tests use Vitest, Testing Library, and jsdom. Each dependency retains its license in its distributed package. package-lock.json records the installed dependency tree.

Headings use Georgia when available, then Times New Roman and the user's serif fallback. Body text uses the system sans-serif stack. Fonts are not redistributed. The original static social preview uses text rasterized with system fonts. Ambient audio is synthesized locally using Web Audio sine oscillators.
